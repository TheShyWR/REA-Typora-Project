# 0.5.0 完成度评估

评估依据：2026-10-23 的 0.5.0 功能与验收；发布整理核对日期：2026-10-25。结论：**约 35%，合理区间 30%–40%**。

## 基准和计算方式

主要基准是本机 Typora **1.9.4 / 7260 的 macOS 编辑体验**，结合 [官方功能介绍](https://typora.io/) 与 [官方支持目录](https://support.typora.io/) 核对功能范围。官方文档会随版本变化；这里不声称已经追平当前最新 Typora，也不包含 Windows/Linux、购买和授权系统的复现。

采用人工功能权重，分数结合已实现能力和已有验收覆盖。尚未实测的交互不按完成计；源码保护仅说明保留原文，不等于该语法已具有完整富文本编辑能力。

|---|---:|---:|---:|---|

权重并非行业标准，分数也不是精确测量值。34.95 只是这组判断的算术结果，不应宣传为“精确兼容 34.95%”。若把跨平台或全部第三方导出能力纳入分母，完成度还会降低。

## 证据强度

- 原版行为直接对照：基础无序列表键盘序列、无编辑的源码/排版往返；段落专注部分对照。
- 本机应用实测：文件读写、保存冲突、两类异常终止恢复、中文路径图片、图片粘贴、撤销重做及重启后显示。
- 自动化：整理前 15 项 JS 检查、Swift DocumentStore 和 ImageAssets 检查。部分控制器测试使用模拟边界，不能替代真实输入法、WebKit 和跨窗口操作。
- 未完成：不能用安装了某个编辑器依赖、出现了某个按钮或保护模式保留了源码，推断对应 Typora 功能已经完整实现。

## 建议的后续顺序

1. 完成拖放、真实拼音输入、复杂撤销/选区的实机验证与修正。
2. 递归文件树、搜索替换、文件监听和重命名/移动。
3. 扩展语法、公式/图表及表格编辑兼容。
4. 附件迁移、图片缩放、导出/打印和主题设置。
5. 多窗口、性能、无障碍、签名和发布完善。
