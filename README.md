# REA Typora Project · 0.8.0

一个以 Typora 编辑体验为目标、分阶段实现的独立 macOS Markdown 编辑器。应用名称为 **REA Markdown**，使用 **Swift / AppKit + WKWebView + Milkdown Crepe**。目前可以在本机打开、编辑、保存 Markdown，并处理本地图片与图片剪贴板。

**当前是可运行的阶段版本，不是完整 Typora 替代品。** 项目与 Typora 官方无隶属关系。图标采用项目所有者指定的 Typora 原版图标，资源归属和许可证边界见 [第三方声明](THIRD_PARTY_NOTICES.md)。

**当前源码版本：0.8.0。GitHub Release 安装包仍为 0.5.0。** 本次新增文件监听、外部变化提示与当前文件重命名；0.8.0 安装包可通过下面的命令在本地生成。

[下载已发布的 0.5.0](https://github.com/TheShyWR/REA-Typora-Project/releases/tag/v0.5.0) · [版本记录](CHANGELOG.md) · [完成度评估](docs/PROGRESS.md) · [验收说明](docs/VALIDATION.md)

## 目前能做什么

- 打开和保存 UTF-8 `.md`、`.markdown`、`.txt`，支持新建、另存为。
- 排版编辑与源码模式切换；基础标题、行内格式、列表、引用、任务列表、表格和代码编辑由 Milkdown 提供。基础列表键盘操作已有原版样例对照，其他复杂行为仍需补测。
- 无编辑保存保留原始字节，包括 UTF-8 BOM 和 CRLF；无法可靠往返的语法自动进入源码保护，可继续编辑保存，不将它误当作已完整支持的富文本语法。
- 主动提示当前磁盘文件外部修改或删除，支持确认后重新载入或另存为，避免直接覆盖；本地恢复草稿支持异常退出后的未保存内容恢复。
- 显示本地图片，保留中文相对路径和替代文本；插入按钮自动复制图片到文档旁的附件目录。
- 排版模式支持图片粘贴。已实测从 macOS 预览复制图片内容、从 Finder 复制 PNG 文件；撤销、重做、保存并重启重开后仍可显示。
- 可逐层展开的目录树、磁盘变化自动更新、手动刷新、当前文档高亮与定位及同目录重命名；目录优先排序，支持中文和空格路径。
- 当前文档查找与替换：匹配数量、上一个/下一个、大小写选项、单次和全部替换；支持排版与源码模式及撤销。
- 基础大纲、段落专注和明暗主题切换；提供初步 PDF 导出入口，完整排版和资源质量尚未验收。

## 完成度：0.5.0 基线约 35%

截至 0.5.0，按 macOS 功能范围和实际验证证据加权，估计完成 **约 35%**，合理区间 **30%–40%**。这是工程判断，不是自动测得的兼容率，也不是“写完五个版本就完成一半”。

当前进展主要集中在文件读写、恢复和基础图片流程。Typora 式符号显隐与精确选区、真实输入法候选态、扩展语法、跨文件搜索、附件迁移、完整主题与打字机、导出、多窗口及性能仍有较大缺口。0.6.0 补齐基础目录树，0.7.0 增加文档内搜索替换，0.8.0 增加文件监听和重命名；尚未重新评定整体验收分数。详见 [评分口径与证据](docs/PROGRESS.md)。

## 下载与运行

在 [Releases](https://github.com/TheShyWR/REA-Typora-Project/releases) 下载 `REA-Markdown-0.5.0-macos-arm64.zip`，解压后打开 `REA Markdown.app`。运行不需要 Node.js；本地文件编辑不需要网络。

- 已发布的 0.5.0 和本地 0.8.0 构建均为 Apple Silicon / arm64。
- 构建目标：macOS 13.0+；尚未在全部旧系统版本验收。
- 签名：本机 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。
- `.sha256` 文件用于校验下载包。

## 从源码构建

需要 macOS、Xcode 或含 macOS SDK 的 Command Line Tools，以及 Node.js 22.12+（本机验证使用 Node.js 24）。

```sh
git clone https://github.com/TheShyWR/REA-Typora-Project.git
cd REA-Typora-Project
npm ci
npm run build:mac
open "release/REA Markdown.app"
```

远程 `main` 当前为 0.8.0，上述命令可构建最新版。Release 中的预编译安装包仍为 0.5.0。

`npm start` 会构建并打开；`npm run package:mac` 生成 ZIP 和 SHA-256 文件。构建采用当前 Mac 的 CPU 架构，Intel 构建尚未验收。构建中现有的 WebKit 文件类型 API 弃用、IIFE 动态语言加载警告尚未全部消除。

## 工作空间目录树（0.6.0）

点击侧栏“＋”或“文件 → 打开文件夹…”，展开各级目录后点击文档打开。刷新按钮重新读取目录并保留展开状态；定位按钮展开当前文档的父目录并聚焦该文件。两项操作也可从“文件”菜单调用。

仅展示普通目录和 `.md`、`.markdown`、`.txt` 文件，隐藏文件、符号链接和应用包不显示。按需读取展开的目录。0.8.0 增加自动更新与当前文件重命名，使用方式如下；跨文件搜索、新建目录和文件移动尚未实现。工作空间和展开状态暂不跨应用重启保存。

## 查找与替换（0.7.0）

`⌘F` 打开搜索，`⌘G` / `⇧⌘G` 查找下一处 / 上一处；搜索框内 Enter / Shift+Enter 也可导航。按 Esc 关闭面板。可选区分大小写，替换内容留空表示删除。单次替换后继续定位下一处；全部替换使用一次可撤销编辑，按 `⌘Z` 撤销、`⇧⌘Z` 重做。

- 排版模式搜索正文，可跨相邻的粗体/普通文字，但不跨段落、图片等边界。图片替代文本与链接 URL 不计入正文匹配；未匹配区域格式和链接目标保留。
- 源码模式搜索原始 Markdown，包括标记、Front Matter 和链接地址。CRLF 文档在替换、撤销和保存后保留换行约定；磁盘 BOM 由文档存储层保留。
- 当前仅支持文档内单行普通文本搜索，不支持正则、全词、跨文件搜索或替换。排版模式显示全部匹配高亮；源码模式使用当前匹配选区。超大文档和大量匹配的性能尚未专项验收。

## 文件监听与重命名（0.8.0）

所选工作空间根目录及已访问的子目录会监听磁盘条目变化，自动更新列表并保留展开状态；未变化的目录不会重建界面。当前文档单独监听，兼容原地写入、原子替换、删除及恢复；切回应用时也会重新检查。这里不是对整个工作空间进行递归扫描。

磁盘文件被外部修改、删除或无法读取时，顶部显示提示，编辑区保持原内容。点击“重新载入磁盘版本”才能加载磁盘内容；存在未保存修改时需要确认，取消后继续保留本地编辑。也可“另存为…”保留当前版本。常规保存仍会检查磁盘基线并拒绝冲突覆盖，没有自动合并。

保存当前文档后，点击侧栏或“文件”菜单的“重命名当前文件…”。只在同一目录修改文件名，支持 `.md`、`.markdown`、`.txt` 扩展名，不覆盖已有文件。窗口标题、目录高亮、后续保存和恢复草稿路径同步更新；编辑区和撤销历史不重建。原有附件目录和 Markdown 图片链接不改动，因父目录相同仍可读取。改名后新插入的图片可能进入新文件名对应的附件目录。

尚不支持重命名文件夹、跨目录移动或自动跟随外部改名。外部移走文件会显示删除/移动提示；在大小写不敏感的磁盘上仅更改大小写时，需要先使用中间名称。大量目录和网络卷尚未专项验收。

## 图片与文档安全

先保存文档，再插入或粘贴图片。附件保存在 `<文档名>.assets/`，Markdown 使用相对链接。允许 PNG、JPEG、GIF、WebP；实机测试集中在 PNG。单张或一次粘贴/拖放批次总量最多 20 MB。

文件拖入排版区域已接入持久化导入流程，实际跨窗口拖放手势仍待验收。源码模式请使用顶部“图片”按钮。移动文档时需同时携带附件并保持目录结构；跨目录另存为不会自动迁移附件。撤销插图不会自动删除附件。

草稿存放在 `~/Library/Application Support/local.rea.markdown/Recovery/`，是本机明文恢复文件；显式保存才更新原文档。恢复不能保证捕获异常终止瞬间尚未从 WebKit 发出的字符；保存冲突检测也不是跨进程事务锁。

## 工程结构

```text
src/                      Web 编辑器、图片、源码保护和样式
native/                   AppKit / WebKit 桥及文档、图片存储
  Resources/AppIcon.icns   应用图标（第三方资源）
scripts/                  构建、打包、第三方许可收集
docs/                     完成度、验收和第三方许可
index.html                编辑器页面入口
vite.config.js            Web 资源构建配置
package.json              开发依赖与命令
package-lock.json         可复现依赖锁定
CHANGELOG.md              0.1.0—0.8.0 阶段记录
LICENSE                   仓库原有 MIT 许可证
THIRD_PARTY_NOTICES.md     第三方归属与许可证边界
```

`node_modules/`、`build/`、`dist/`、`release/` 是本机构建产物，不提交 Git。旧 Electron 实验、REA 分析转储、测试脚本和临时样例已按项目所有者要求移出发布工程；验收结论保留在文档中，本仓库当前不提供 `npm test` 命令。历史测试不等于每个未来提交都会自动验证。

## 开发过程

| 版本 | 阶段目标 | 实际进展 |
|---|---|---|
| 0.1.0 | 先做出能运行的本机编辑器 | 建立原生窗口与 Web 编辑器，完成 Markdown 打开、编辑、保存和源码切换；尝试过的 Electron 路径后来移除 |
| 0.2.0 | 优先保证文档可靠性 | 增加原始字节基线、外部修改冲突检查、恢复草稿、BOM/CRLF 保留和源码保护 |
| 0.3.0 | 开始对照原版编辑行为 | 修复模式往返焦点，调整列表序列化，实现段落专注；部分列表和模式切换序列与 Typora 对照通过 |
| 0.4.0 | 补齐本地图片和附件 | 支持中文路径显示、保留 alt 与路径、原生图片选择器、附件复制及文档上下文隔离 |
| 0.5.0 | 图片剪贴板持久化 | 支持预览/Finder 图片粘贴，先写附件再插入；加入批次校验、导入期间保护和文档切换取消；接入拖放流程 |
| 0.6.0 | 目录树与文档定位 | 按需展开嵌套目录、手动刷新、当前文件高亮和定位；工作空间路径边界校验；本机版本 |
| 0.7.0 | 文档内搜索与替换 | 正文/源码分开匹配，计数、循环导航、大小写、单次/全部替换和撤销；修正 CRLF 撤销后的修改状态；本机版本 |
| 0.8.0 | 文件变化与重命名 | 目录自动更新、当前文件外部修改/删除提示、确认重载、同目录重命名与图片路径保留；源码已同步 GitHub |

前五个版本是实际开发阶段的整理，**不是五个可以逐个检出的历史提交**。仓库保留原始初始化提交，首个完整工程快照为 0.5.0；该版本发布时另补应用图标、便携构建脚本和发布文档。0.6.0—0.8.0 在此基础上继续开发，没有将未实现功能计作完成。
