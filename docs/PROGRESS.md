# Typora 复刻完成度

截至 2026-10-28，本机 **0.13.0 暂维持约 46%**，工程估计区间 **41%–51%**。上一版 0.12.0 约 **46%**，本版变化 **0 个百分点**。新建功能已开发并通过自动化验证，原生界面待实测，以下分项继续沿用 0.12.0 已验收基线。

范围沿用最初约定：本机 Typora 1.9.4 / 7260 的 macOS 编辑、文件管理、写作、导出和桌面体验；不包含 Windows/Linux、购买或授权系统。不是对所有平台、当前最新版全部功能或代码相似度的测量。权重保持不变，估计区间表示人工判断的不确定性，不是统计置信区间。

## 证据强度

- 原版行为直接对照：基础无序列表键盘序列、无编辑的源码/排版往返；段落专注部分对照。
- 本机应用实测：文件读写、保存冲突、两类异常终止恢复、中文路径图片、图片粘贴、撤销重做及重启后显示。
- 自动化：整理前 15 项 JS 检查、Swift DocumentStore 和 ImageAssets 检查。部分控制器测试使用模拟边界，不能替代真实输入法、WebKit 和跨窗口操作。
- 未完成：不能用安装了某个编辑器依赖、出现了某个按钮或保护模式保留了源码，推断对应 Typora 功能已经完整实现。
