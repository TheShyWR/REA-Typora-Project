- 真实应用：正文搜索 `cat` 有 4 处，区分大小写后 3 处；上一个从首项循环到末项；全部替换三处为中文，粗体和链接目标保留；一次撤销恢复原文与无修改状态，重做并保存后磁盘内容符合预期。
- 真实应用：Front Matter 源码保护文档使用 UTF-8 BOM 和 CRLF；空替换删除一处、全部替换三处，均可一次撤销；修正换行状态后，撤销回原文显示无未保存修改。重做并保存的完整字节与预期一致，BOM、CRLF 和 Front Matter 未丢失。
- 切换文档和模式：同一查询在源码包含链接地址（2 处），排版仅匹配正文（1 处）；中文查询显示 3 处高亮。`⌘G` / `⇧⌘G` 导航计数通过实机验证。

## 0.5.0 功能验收依据（2026-10-23）

以下结论来自开发期间的本机 UI 测试和自动化检查，不代表完整 Typora 兼容测试。

| 范围 | 已验证内容 | 仍缺少的验证 |
|---|---|---|
| 文件读写 | UTF-8、无编辑保存的 BOM/CRLF、中文编辑后立即保存 | 非 UTF-8 支持、超大文档压力 |
| 外部冲突 | 原文件外部改写后拒绝覆盖，可另存为；恢复后冲突仍生效 | 多进程同时保存的事务锁 |
| 恢复 | 已命名及未命名草稿实际异常终止后恢复，损坏草稿检查 | 断电、磁盘满、WebKit 崩溃边界 |
| 源码保护 | Front Matter、脚注和 HTML 等内容在保护模式编辑后保留 | 对应语法的完整富文本编辑 |
| 原版对照 | 基础无序列表序列、无编辑模式往返后继续输入和撤销；段落专注部分对照 | 符号显隐、复杂选区、IME 候选态、精确光标映射 |
| 本地图片 | 中文空格路径、alt 和路径保留、插入与附件落盘、同名图片跨目录隔离 | 全部图片格式、动画、缩放、附件自动迁移 |
| 图片剪贴板 | 预览图片内容、Finder PNG 文件粘贴，撤销重做，保存和重启重开 | 系统截图快捷键、第三方截图工具、富 HTML 剪贴板 |
| 拖放 | 已接入与粘贴相同的持久化流程，导入逻辑有测试 | 实际跨窗口拖放手势 |
| PDF | 有导出入口，导出时暂时撤掉专注淡化 | 分页、图片和字体资源、打印、多格式导出 |

## 已知限制

源码保护保守，部分普通 Markdown 格式也可能进入源码模式。保护文档暂不支持排版 PDF 导出。附件不自动清理，也不随跨目录另存为迁移。无多窗口、完整搜索替换、完整主题设置和正式签名公证。恢复草稿为本机明文，尚未离开 WebKit 的最后输入不能保证被快照捕获。
