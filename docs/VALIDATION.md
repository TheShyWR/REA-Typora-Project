# 0.5.0 验收说明

## 功能验收依据（2026-10-23）

以下结论来自开发期间的本机 UI 测试和自动化检查，不代表完整 Typora 兼容测试。

| 范围 | 已验证内容 | 仍缺少的验证 |
|---|---|---|
| 文件读写 | UTF-8、无编辑保存的 BOM/CRLF、中文编辑后立即保存 | 非 UTF-8 支持、超大文档压力 |
| 外部冲突 | 原文件外部改写后拒绝覆盖，可另存为；恢复后冲突仍生效 | 多进程同时保存的事务锁 |
| 恢复 | 已命名及未命名草稿实际异常终止后恢复，损坏草稿检查 | 断电、磁盘满、WebKit 崩溃边界 |
| 源码保护 | Front Matter、脚注和 HTML 等内容在保护模式编辑后保留 | 对应语法的完整富文本编辑 |
| 原版对照 | 基础无序列表序列、无编辑模式往返后继续输入和撤销；段落专注部分对照 | 符号显隐、复杂选区、IME 候选态、精确光标映射 |
| 本地图片 | 中文空格路径、alt 和路径保留、插入与附件落盘、同名图片跨目录隔离 | 全部图片格式、动画、缩放、附件自动迁移 |
| 图片剪贴板 | 预览图片内容、Finder PNG 文件粘贴，撤销重做，保存和重启重开 | 系统截图快捷键、第三方截图工具、富 HTML 剪贴板 |
| 拖放 | 已接入与粘贴相同的持久化流程，导入逻辑有测试 | 实际跨窗口拖放手势 |
| PDF | 有导出入口，导出时暂时撤掉专注淡化 | 分页、图片和字体资源、打印、多格式导出 |

## 发布整理前检查

- 15 项 JS 检查通过，其中部分控制器检查使用模拟边界。
- Swift DocumentStore 与 ImageAssets 检查通过，包括字节基线、恢复、冲突、图片路径和批次导入。
- 图片测试样例曾在本机缺失；从已有验收副本恢复后重新运行通过。不是在缺失样例的失败状态下记录为通过。
- 按所有者要求，历史测试、原版分析和临时样例已移出本仓库，保留本机独立备份。仓库没有当前可运行的 `npm test`；未来修改需重新建立适用检查。

## 发布验证（2026-10-25）

- 从锁文件重新执行 `npm ci` 成功，安装 223 个包；没有使用旧 Electron 或测试目录。
- `npm run package:mac` 完成 Web 资源、Swift 原生程序和 ZIP 构建；`codesign --verify --deep --strict` 通过。本机为 arm64，部署目标为 macOS 13.0。
- 重新启动最终应用，在“关于”窗口确认 Typora 图标和 `0.5.0 (5)`；图标文件 SHA-256 与本机原版资源一致。
- 用最终应用打开独立 `.md` 样例，在排版模式粘贴中文，保存后检查磁盘原文和源码视图，内容一致且没有未保存标记。这不是输入法候选态验收。
- 发布 ZIP 附带 SHA-256 校验文件；实际启动检查针对与 ZIP 同一次构建的应用副本。
- 保留原始初始化提交及原有 LICENSE；源码和发布包不含授权 token、原版分析转储或历史测试样例。

## 已知限制

源码保护保守，部分普通 Markdown 格式也可能进入源码模式。保护文档暂不支持排版 PDF 导出。附件不自动清理，也不随跨目录另存为迁移。无多窗口、完整搜索替换、完整主题设置和正式签名公证。恢复草稿为本机明文，尚未离开 WebKit 的最后输入不能保证被快照捕获。
